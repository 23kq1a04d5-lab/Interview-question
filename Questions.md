1.What is C?
Answer: C is a general-purpose programming language.
2.Who developed C?
Answer: Dennis Ritchie.
3.What is a variable?
Answer: A variable stores data in memory.
4.What is a data type?
Answer: It defines the type of data a variable can store.
5.What is printf() used for?
Answer: It displays output on the screen.
6.What is scanf() used for?
Answer: It takes input from the user.
7.What is a loop?
Answer: A loop repeats a block of code.
8.Name three types of loops in C.
Answer: for, while, and do-while.
9.What is an if statement?
Answer: It is used to make decisions based on a condition.
10.What is a function?
Answer: A function is a block of code that performs a specific task.
